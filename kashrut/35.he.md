## דף עזר (התמונה הכללית)

| מגע | עומק הבליעה |
|---|---|
| **צונן** | אין בליעה: שטיפה או גירוד |
| **כלי ראשון** (45 מעלות ומעלה, גם כשהוסר) | בישול גמור: צריך שישים |
| **עירוי** מכלי ראשון | כדי קליפה |
| **כלי שני** | לכתחילה כדי קליפה; כלי שלישי: כצונן. גוש: לכתחילה להחמיר |
| **צלייה יחד** | שמן: הכול (שישים); כחוש: כדי נטילה |
| **תתאה גבר; מליח; כבוש** | התחתון גובר; מליח כרותח; יממה בנוזל = מבושל |

## א. צונן

- להיזהר ממגע, אך יבשים וקרים ← מותר בלי שטיפה (לנער פירורים). לחות או שמנונית ← שטיפה (ושפשוף).
- בשר נגע בגבינה רכה ← לזרוק מה שנגע בגבינה, לשטוף את הבשר.
- לחם נגע בבשר לח ← מותר עם בשר; לחלב – לגרד את המקום (אי אפשר לשטוף).
- בשר חי נפל לחלב צונן ← לשטוף את הבשר; החלב מותר. רמ"א: מבושל או צלוי ← קליפה; בקעים או תבלין חריף ← הכול אסור אלא בהפסד מרובה.

## ב. בישול בכלי ראשון

- סיר על האש מערב טעמים לגמרי ← צריך שישים.
- הוסר מהאש אך עדיין לפחות **יד סולדת** (כ־45 מעלות) ← עדיין כבישול. פחות ← כצונן.
- גם אם פעמים רבות אינו מבשל, חכמים קבעו כבישול גמור (בהיעדר גוי אמין); הוצאת האיסור אינה מועילה בלי שישים.

## ג. עירוי מכלי ראשון

- עירוי מכלי ראשון מבשל **כדי קליפה** (השכבה הדקה ביותר שניתן לקלף).
- רוטב טרף רותח על בשר ← מקלפים את הפנים ושוטפים את השאר.
- עירו רותחים על חתיכה כשרה ונבילה יחד ← מקלפים את הכשרה.

## ד. כלי שני, שלישי וגוש

- **כלי שני**: דפנותיו לא היו על האש ← אינו מבשל; לכתחילה חוששים לכדי קליפה (קישוא במרק טרף ← לקלף).
- **כלי שלישי** ועירוי מכלי שני ← כצונן.
- **גוש** (בשר, פשטידה, תפוח אדמה) שומר חום: יש אומרים שמבשל אף בכלי שלישי כל זמן שהיד סולדת. לכתחילה להחמיר, בהפסד מרובה להקל.

## ה. ביאור כללי התערובות

- הכללים הם **גדרים** למצבי ספק, לא קביעה על המציאות. רוב הטעמים בטלים בארבעים, אך חזקים צריכים שישים, ולכן שישים לכולם.
- בלי שישים הוצאת הטרף אינה מועילה, והוא יכול לאסור גם תבשיל שני ושלישי (שמא בכל פעם יצא כל הטעם). אין חילוק בזמן השהייה.
- גוי אמין פותר את הספק (נוהגים רק בהפסד מרובה).
- המחלוקות הן עד היכן להרחיק את הגדר: מקרים רחוקים – כן, נדירים מאוד – לא. הרגיש בכל זאת טעם איסור? יפסיק; על מה שאכל לא עבר.

## ו. צלייה

- חתיכה כשרה וטרפה שנצלו נוגעות: אם אחת **שמנה**, הטעם מפעפע בכולה ← צריך שישים. שתיהן **כחושות** ← מסירים **כדי נטילה** (רוחב אצבע, כ־1.9 ס"מ).
- קשה לקבוע שומן ← מחמירים כשתי האפשרויות: בלי שישים ← אסור; עם שישים ← כדי נטילה. מאכל שברור שכחוש ← רק נטילה.

## ז. תתאה גבר

- החום עולה, ולכן **התחתון גובר**.
- טרף קר לתוך מרק כשר חם ← בישול גמור ← צריך שישים כנגד החתיכה.
- טרף חם לתוך מרק כשר קר ← רק קליפה ← שישים כנגד קליפתו.
- שתי חתיכות זו על זו: התחתונה חמה ← כצלי שמן; התחתונה קרה ← לקלף את הכשרה במקום המגע.

## ח. מליח כרותח

- מאכל שאינו נאכל מרוב מלח, שנגע ברטיבות, מבליע טעם **כרותח**. המלוח נותן ואינו מקבל.
- בשר מלוח על גבינה תפלה ← הגבינה נפגעת; הבשר – שטיפה. שניהם מלוחים ← שניהם.
- כחושים: קליפה. שמן: הכול, אלא אם יש שישים. לא ברור ← להחמיר כשתי האפשרויות.

## ט. כבוש כמבושל

- שרויים יחד בנוזל **יממה** שלמה ← כבישול ← צריך שישים.
- בנוזל מלוח או חריף מאוד ← כבר אחרי כ־18 דקות; פחות ← קליפה.
- כלים: מרק טרף יממה בסיר ← לכתחילה להגעיל; מה שכבר בושל בו ← מותר.

## י. ריח וזיעה

- עוגה שקלטה ריח נבילה שמנה שנאפתה עמה: לכתחילה להיזהר, אך בדיעבד **ריח אינו אוסר**.
- **זיעה** מרובה תחת מכסה משותף ← אוסרת (רמ"א). קישואים שכיסו סיר מרק טרף ← אסורים.

> משפט לזכור: חום מלמטה מבשל עד הסוף; חום מלמעלה רק שורט את הקליפה.
